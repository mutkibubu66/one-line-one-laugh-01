# One Line, One Laugh

[![make.fun bounty](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a)](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a)

## The line

> My smart fridge just sent me a breakup text - apparently I've been sneaking out with the takeout menus behind its back.

The setup is a gadget everyone owns: the smart fridge that judges your
groceries. The punchline turns it into a jealous partner — it caught you
cheating on it with takeout menus.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — one line, 119 characters,
valid UTF-8 — and prints it to stdout.
